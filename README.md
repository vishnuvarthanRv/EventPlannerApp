# 📅 Event Planner Android Application

## 📌 Project Description

The Event Planner Android Application is designed to help users organize and manage their daily events and important activities. Users can create, view, edit, and delete events, set reminders, and search for upcoming events.

This application provides a simple and user-friendly interface to manage personal schedules efficiently.

## ✨ Features

* ➕ Add new events
* ✏️ Edit existing events
* 🗑️ Delete events
* 📅 Select event date
* ⏰ Select event time
* 🔔 Set event reminders
* 🔍 Search events
* 📋 View past events
* 💾 Save event details locally

## 🛠️ Technologies Used

* **Programming Language:** Java
* **UI Design:** XML
* **IDE:** Android Studio
* **Local Storage:** SharedPreferences
* **Notifications:** Android Notification System
* **Reminder Scheduling:** AlarmManager

## 📱 Application Requirements

* Android Studio
* Android SDK
* Minimum Android Version: Android 7.0 (API Level 24)
* Java Development Kit (JDK 11)

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open Android Studio.
3. Select **Open** and choose the project folder.
4. Wait for Gradle Sync to complete.
5. Connect an Android device or start an emulator.
6. Click the **Run** button to launch the application.
